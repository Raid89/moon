# Moon — Components and Layout

## Principio de layout
Moon debe sentirse dinámica, emocional y moderna.
La web no debe parecer un dashboard.
Debe parecer una experiencia / landing social con storytelling visual.

## Tipos de secciones prioritarias
La estructura general de Moon puede incluir:

- Hero principal
- Sección de propuesta de valor
- Cómo funciona
- Beneficios / características
- Testimonios o prueba social
- Vista de planes o experiencias
- CTA final
- Footer con navegación clara

## Hero section
El hero debe:
- comunicar la propuesta de valor en segundos
- incluir a la mascota o elementos icónicos
- usar titular emocional y potente
- mostrar comunidad, planes y diversión
- tener CTA principal muy visible

### Debe incluir
- titular potente
- subtítulo claro
- CTA primario
- CTA secundario opcional
- imagen o ilustración protagonista
- elementos gráficos de apoyo

## Cards
Las tarjetas son clave en Moon.
Deben sentirse:
- suaves
- amigables
- redondeadas
- visualmente limpias
- con información priorizada

### Usos
- planes
- categorías
- testimonios
- beneficios
- previews de eventos
- miembros o comunidad

## Botones
Los botones deben ser muy claros y expresivos.

### CTA principal
- color naranja de marca
- texto oscuro o muy contrastado
- bordes redondeados
- presencia fuerte

### CTA secundario
- fondo oscuro o transparente
- borde sutil
- look elegante pero coherente con el tono juvenil

## Navegación
La navegación debe ser simple.
Evitar menús recargados.

Puede incluir:
- logo
- enlaces clave
- CTA destacado
- hamburguesa en móvil

## Secciones con storytelling
Moon se beneficia de composiciones en bloques que alternen:

- texto + ilustración
- mockup + beneficio
- grupo social + mensaje emocional
- iconos + descripciones cortas

## Marcos tipo foto
La imagen referencia usa marcos de fotografía / recuerdo.
Esto puede convertirse en un recurso visual de marca.

Usarlo en:
- galerías
- testimonios visuales
- highlights de experiencias
- contenido promocional

No convertirlo en patrón obligatorio en todo el sitio.

## Jerarquía visual
Cada bloque debe responder:
1. Qué es esto
2. Por qué importa
3. Qué puedo hacer aquí

El orden visual debe ser:
- titular
- mensaje clave
- apoyo visual
- CTA

## Responsive
El layout debe diseñarse mobile-first.

### En móvil
- bloques apilados
- titular corto
- CTA visible sin esfuerzo
- imágenes optimizadas
- navegación simple

### En desktop
- aprovechar más composición
- alternar bloques visuales
- usar diagonales suaves o fondos con profundidad
- mantener orden, no caos

## Qué evitar
- grids excesivamente rígidos
- secciones visualmente idénticas
- exceso de texto
- demasiados estilos de tarjeta distintos
- fondos blancos en toda la página
- interfaces tipo admin panel
