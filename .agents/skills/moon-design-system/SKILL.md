# Moon Design System

## Purpose

Maintain Moon's visual identity and provide a consistent,
modern, expressive and accessible user experience.

## Core Principles

- Playful minimalism with a strong visual personality.
- Warm nighttime aesthetic.
- Black, vibrant orange and cream color palette.
- Expressive and recognizable Moon mascot.
- Dynamic layouts without unnecessary complexity.
- Responsive and accessible interfaces.
- Reusable Angular components.

## Design Workflow

1. Understand the purpose of the requested page or component.
2. Review the applicable design references.
3. Reuse existing tokens and components.
4. Define the visual structure and interactions.
5. Implement following Angular best practices.
6. Review visual consistency, accessibility and performance.

## Rules

- Never invent a new visual identity for Moon.
- Never modify the mascot's defining characteristics.
- Do not force the mascot into every section.
- Prefer existing design tokens and components.
- Avoid generic dashboard aesthetics.
- Do not add animations without a clear purpose.
- Respect accessibility and reduced-motion preferences.
- Use the Angular conventions established in the project.
