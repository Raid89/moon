# Catálogo DIVIPOLA

`divipola.json` es una copia reducida al código y nombres de departamento/municipio del conjunto
oficial DIVIPOLA de DANE, descargado el 15 de octubre de 2026 desde
https://www.datos.gov.co/Mapas-Nacionales/DIVIPOLA-C-digos-municipios/gdxc-w37w .

El catálogo se usa en tiempo de ejecución para no depender de una API externa durante el registro.
